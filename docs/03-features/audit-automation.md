# 감사 자동화

## 구현된 흐름

```text
감사자료 업로드
  → 합계잔액시산표·재무제표 파싱
  → 대차평형 및 계정별 대사
  → 변동성·위험 분석
  → 회계기준 RAG 매칭
  → 조서 초안 생성
  → 마스터 저장
  → 검토
  → 승인
```

## 확인된 구현

- 실제 회계프로그램 형식의 합계잔액시산표 5컬럼 구조 파싱
- 재무상태표와 손익계산서 항목 파싱
- 대차평형과 시산표·재무상태표 계정별 차이 계산
- 동일 계정명이 반복될 때 등장 순서 기준 매칭
- 위험 유형별 감사 절차와 종합 결론 생성
- 조서 버전 저장과 상태 이력 관리
- 고객용 분석보고서에서 실데이터가 없을 때 안내 표시

## 제한사항

- 손익계산서는 결산 후 시산표 잔액이 0이 되는 구조 때문에 잔액 기준 대사를 수행하지 않는다.
- 계정과목 표준매핑은 부분 자동화와 수동 오버라이드가 필요하다.
- 분개장과 다중계정 계정별원장 파싱은 미완료다.
- 과거 문서의 P0~P5 상태는 시점별 기록이므로 현재 상태는 별도 재검증이 필요하다.

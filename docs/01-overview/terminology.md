# 용어

| 용어 | 의미 |
|---|---|
| 포털 | `landing_page` 저장소의 Flask 통합 애플리케이션 |
| 고객 포털 | 고객사가 자료를 제출하고 결과를 조회하는 화면 |
| 마스터 포털 | 회계법인 담당자가 회사와 업무를 관리하는 화면 |
| 기업진단 | `WORK_kds`에서 연계하려는 재무자료 분석 업무 |
| 감사 자동화 | 자료 파싱, 대사, 위험 분석, 조서 생성·승인 흐름 |
| RAG | 검색 결과를 언어 모델 응답에 결합하는 구조 |
| Dify | RAG 및 대화 워크플로를 구성하는 서비스 |
| ChromaDB | 회계·감사 지식 청크의 벡터 검색 저장소 |
| 운영 | 실제 사용자가 접속하는 배포 환경 |
| staging | 운영 전 기능과 연동을 검증하는 Ubuntu 배포 환경 |
| 조서 | 분석 결과와 감사 절차를 기록하고 검토·승인하는 산출물 |
| ADR | 중요한 설계 결정과 이유를 남기는 기록 |

# 문서 보관소

이 디렉터리는 과거 시점의 변경 기록과 문서 개편 전 원본을 보관한다.

- `legacy`: 2026-07-28 문서 개편 전 기존 Markdown 원본
- `changelog`: 개편 이후 월별 완료 작업 기록
- `migrations`: 완료된 주요 인프라·데이터 전환 기록

보관 문서는 현재 상태의 기준이 아니다. 현재 정보는 [현재 상태](../01-overview/current-status.md)와 각 활성 문서를 따른다.

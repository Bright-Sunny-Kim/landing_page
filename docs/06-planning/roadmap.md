# 로드맵

- 운영 도메인의 실제 배포 대상 확인
- Render와 Ubuntu 역할 확정
- 서비스, 환경변수, 스토리지 실측

## 2. 감사 자동화 완성

- 계정과목 표준매핑
- 분개장과 계정별원장 파싱
- 교차검증과 보고서 출력 강화

- DB·API·작업 실행 구조 설계
- 비식별 데이터 기반 검증

## 4. 운영 단순화

- 객체 스토리지 표준 확정
